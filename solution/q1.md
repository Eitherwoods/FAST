# 理想抛物面模型

## 1.1 抛物面焦点（馈源舱）Q 的位置模型

设抛物面轴线方向向量为 $\mathbf{n}$，则：
$$\mathbf{n} = (\cos\beta\cos\alpha, \cos\beta\sin\alpha, \sin\beta)$$

馈源舱位置向量关系为：
$$\vec{OQ} = -R - F\mathbf{n} = -0.534R\mathbf{n}$$

---

## 1.2 抛物面模型

设抛物面上一点为 $M(x, y, z)$，由抛物面的定义得：
$$|\vec{OM} - \vec{OQ}| = (\vec{OM} - \vec{OQ}) \cdot \mathbf{n} + 2F$$

代入得：
$$(x + 0.534Ra)^2 + (y + 0.534Rb)^2 + (z + 0.534Rc)^2 = (ax + by + cz + 0.534R + 2F)^2$$

其中：

* $a = \cos\beta\cos\alpha$
* $b = \cos\beta\sin\alpha$
* $c = \sin\beta$

---

## 1.3 问题1求解

代入 $\alpha = 0, \beta = \frac{\pi}{2}$ 得：
$$x^2 + y^2 + (z + 0.534R)^2 = (z + 0.534R + 2F)^2$$
